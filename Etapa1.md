# Curso-FullStack
Etapa 1 del TP con Bootstrap

1. Crear una página HTML utilizando Bootstrap.
Debe contener:
- Un título.
- Una descripción.
- Tres productos.
- Una imagen para cada producto.
- Un botón para cada producto.
- Utilizar container.
- Utilizar row.
- Utilizar columnas.
- Utilizar al menos 3 clases diferentes de Bootstrap.
- La página debe funcionar correctamente en computadora y celular.
  
2.   Investigaren en la documentación de Bootstrap y responder ¿Qué hace cada una de estas clases?
     ·container = la caja principal de Bootstrap que limita el ancho máximo del contenido y lo centra en pantalla con márgenes laterales para que la grilla responsive no se desborde.
     ·row = fila horizontal de Bootstrap que actúa como contenedor de las columnas, encargada de agruparlas y alinearlas correctamente mediante márgenes para que encajen sin desbordar el container
     ·col-md-4 = define el ancho de una columna en la grilla de Bootstrap
  col>> indica que es una columna
  md>> se aplica a pantallas medianas en adelante (laptops y computadoras de escritorio, a partir de $768\text{ px}$).
  4>> Ocupa 4 de las 12 partes en las que Bootstrap divide horizontalmente la pantalla
     ·btn = es la clase base de Bootstrap que transforma un enlace o botón normal en un botón estilizado, definiendo su relleno, esquinas redondeadas, alineación y quitando los bordes por defecto.
     ·btn-primary = es el estilo modificador de Bootstrap que pinta el botón con el color azul principal del tema.
     ·text-center = s la clase de utilidad de Bootstrap que sirve para centrar horizontalmente todo el texto y los elementos alineados como texto
     ·card = Clase de utilidad de Bootstrap que sirve para centrar horizontalmente todo el texto y los elementos alineados como texto
